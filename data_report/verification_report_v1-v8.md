# 온톨로지 버전 전체 정리: v1 → v8 (2차 정정판)

2026-08-30 작성 · 독립운동-근대학교 제도·인사 온톨로지(김바로 논문 스키마 기반) v1~v8 전체 이력 — v9 문서와의 대조 검토 후 정정

`#온톨로지` `#TTL` `#버전이력` `#provenance`

> **정정 사항(2차)**: v9 문서와 교차 대조한 결과 다음을 고쳤다 —
> (1) v6의 오산학교 "1907-12-24 확정" 서술에, 그 근거 자체가 이후 v9 검증 트랙에서 무너진 사례라는 점을 명시했다(단순히 "설립일/개교일이 다른 Claim이라 헷갈렸다"는 설명으로는 부족해서, 실제로 무슨 일이 있었는지 그대로 적었다).
> (2) v7의 "사건 날짜 자동상속 금지" 서술을 "처음 등장"이 아니라 "이 프로젝트에서 시간상 최초로 대규모 적용된 지점"으로 고쳤다 — ver3/ver5(별도 병렬 트랙)가 나중에 같은 원칙을 독립적으로 재발견해 명문화한 것과 시간축이 꼬이지 않도록.
> (3) v3의 "그대로 준용" 표현을 "기본 모델로 채택"으로 고쳐 바로 다음 문단과의 자기모순을 없앴다.
> (4) v8의 P0 번호 나열을 서술형으로 풀었다.
> (5) v4~v5 성격 표현에 "범위 확장"을 추가했다.
> (6) 문서 말미에 v9와의 관계를 명시하는 문장을 추가했다.

## 1. 전체 개요 — 8단계의 성격

v1부터 v8까지는 겉보기엔 "버전이 올라간다"는 한 줄로 요약되지만, 실제로는 성격이 뚜렷이 다른 세 국면으로 나뉜다.

- **스키마 전환기 (v1~v3)** — 데이터를 어떤 구조로 표현할 것인가를 결정한 단계. 이항관계 → 사건유형별 클래스 → 원 논문의 단일 Event 스키마로 두 번 전환했다.
- **정합성·메타데이터·범위 확장기 (v4~v5)** — 스키마는 고정하고, 편찬 정보(누가·언제 만들었나)와 중복·충돌 개체를 정리하는 동시에, 도메인 자체를 "구한말 관공립학교"에서 "독립운동-근대학교 네트워크"로 넓힌 단계.
- **사실 검증·불확실성 모델링기 (v6~v8)** — 실제 역사적 사실 하나하나를 재검색해 날짜를 확정하거나, 확정할 수 없다면 "확정할 수 없다는 사실 자체"를 정교하게 구조화한 단계.

> **한 줄 요약**: v1~v3은 "무엇을 어떻게 담을 것인가", v4~v5는 "누가 언제, 얼마나 넓은 범위를 담았는가", v6~v8은 "그 내용이 정말 맞는가, 맞지 않다면 그 불확실성을 어떻게 데이터로 남길 것인가"를 물었다.

## 2. v1 → v2 — 이항관계에서 사건유형별 클래스로

v1은 `["이승훈", "오산학교", "설립"]` 같은 3항 배열을 그대로 `forceLink`에 꽂아 넣는 손으로 짠 D3.js 그래프였다. 관계 하나가 간선 하나였고, 시간·출처·불확실성 같은 부가정보를 담을 자리가 애초에 없었다.

v2에서 처음으로 실제 OWL/Turtle 온톨로지 파일(.ttl)로 전환하면서, `FoundingEvent`·`RoleEvent`·`AppointmentEvent`처럼 사건 유형마다 별도의 클래스를 만드는 방식을 택했다. "설립"과 "임명"이 서로 다른 스키마를 갖게 된 것이다.

## 3. v2 → v3 — 원 논문의 Event 모델을 기본 틀로 채택

v3에서 김바로(한국학중앙연구원) 박사논문의 Event 중심 설계를 기본 모델로 채택해, 사건유형별로 나뉘어 있던 클래스를 단일 **`:Event`** 클래스 하나로 통합했다. 설립도 임명도 해임도 전향도 체포도 확대도 전부 같은 스키마를 쓴다. 다만 이 채택은 "논문을 그대로 복제"한 것은 아니다 — 원 논문의 뼈대(단일 Event 스키마, 학술·추정·조직 모델의 구조)는 그대로 가져오되, 실제 데이터에 맞춰 프로젝트가 임의로 확장·해석한 지점이 함께 존재한다(§3-1 참조).

```text
:Event
    :hasObject     사건의 핵심 참여자/대상
    :hasPreObject  사건 이전 상태(복수 가능)
    :hasPostObject 사건 이후 상태(복수 가능)
    :hasEventType  사건유형(:Term)
    :hasTimeValue  대표 시간값
```

이 통합의 대가로, "최린이 천도교 소속에서 독립선언서 초안 작성자로 임명됨" 같은 관계가 **노드 하나(사건)에 매달린 속성**이 되어버려 그래프 시각화 관점에서는 한 번 더 "접는" 변환이 필요해졌다(이 변환 로직은 별도 시각화 노트에서 다뤘다). 이때 47개체·75관계(v1 기준 환산)를 단일 스키마로 확장 완료했고, 627개 트리플이 Protégé에서 정상 파싱되는 것을 확인했다.

### 3-1. 원 논문을 벗어난 프로젝트 임의 해석

`locatedIn`·`modeledAfter`·`establishedByOrg`·`acquiredBy`·`printedAt`·`ledTo` 같은 관계는 Event로 바꾸지 않고 조직의 정적 상태로 남겨두기로 했는데, 이는 원 논문이 명시한 구분이 아니라 이번 프로젝트에서 데이터 특성에 맞춰 임의로 정한 해석이다. 즉 **"기본 모델은 논문에서, 세부 경계는 프로젝트에서"**로 역할이 나뉜다.

**v3 시점에 이미 인지하고 있던 미완성 지점**: 시간정보 없는 사건 다수(주석으로만 표기), 사건-사건 인과관계(안악사건→105인사건) 미모델링, 체포·확대 계열 사건유형 시소러스 미구축, `hasBibo`가 개별 서지정보 없이 뭉뚱그려짐.

## 4. v3 → v4 — 편찬 메타데이터와 정합성 정리

스키마는 그대로 두고, 다음 네 가지를 정리했다.

1. `hasCompiler`/`hascompiledTime`이 미기입 상태였던 65개 Event 전부에 추가
2. `:백오인사건`의 Group/Event 이중 타입 선언 충돌을 Event로 단일화해 해소

4. 중복 개체 제거: `:이승훈설립오산학교_01` 제거, `:19071201이승훈설립_01`만 유지

## 5. v4 → v5 — hasCompiler를 실제 인물로, 도메인 범위 확장

`hasCompiler` placeholder를 실제 편찬자 개체 `:iteratorfor42`로 전체 치환했다. 이와 별도로 `hasWebResource` 확보를 위해 `hasBibo` 고유 출처 49건을 매체·항목명·인용횟수로 정리한 확보표(xlsx)를 만들어 하나씩 직접 검색해 채워 넣는 작업을 병행했다. 이 시점에서 프로젝트 도메인이 "구한말 관공립학교"에서 "독립운동-근대학교 네트워크"(이승훈·안창호·신민회·신흥무관학교 등 47개체)로 확장되었다 — **단순한 메타데이터 보강이 아니라 다루는 범위 자체가 넓어진 전환점**이었다.

## 6. v5 → v6 — 3회차 검토 결과 반영: 필수 수정 4건 + 날짜 확정 5건

v6은 처음으로 "검토안"이라는 외부 대조 문서를 기준으로 움직인 버전이다.

### 6-1. 반드시 수정해야 했던 것 4가지

1. **안명근체포**: `hasEventType`은 이미 3회차에서 `:임명` → `:체포`로 고쳐져 있었지만, `hasTimeValue`는 여전히 "1910-11-01"로 남아 있었음을 발견. 안악사건·안명근·105인사건 3개 항목이 모두 "1910년 12월 평양역 체포"로 일치함을 웹검색으로 재확인해 1910-12-01(±1개월)로 수정, URI도 `19101101`→`19101201`로 변경.
2. **오산학교-대성학교 승계관계 삭제**: `:오산학교 :succeedByPersonTo :대성학교` 트리플이 3회차에도 여전히 남아 있던 것을 발견해 제거. 두 학교가 조직적으로 승계 관계에 있다는 근거는 없고, 같은 교육구국운동 계열의 병렬적 설립 사례로 보는 것이 타당하다고 판단.
3. **오산학교 개교일 재검증**: 기존 1907-12-01(추정, ±1개월)을 독립운동인명사전(한국독립운동정보시스템, 국가보훈부 산하 공식 DB)·위키백과·나무위키 등 복수 출처와 대조한 결과 "1907년 12월 24일"로 일치. 1907-12-24로 수정하고 `hasEestimation`을 "0"(확정)으로 처리. 검토안 문서 자체는 "1907년 11월 24일"이라고 주장했으나 이때는 확인되지 않아 채택하지 않았다. **단, 이 판정은 v9 검증 트랙(§10 참조)에서 다시 뒤집힌다** — "복수 출처 일치"라는 확정 근거 자체가 사실은 두 종류의 서로 다른 서술을 억지로 하나로 합친 것이었음이 나중에 드러난다.
4. **사건 확대 구조 2단계화**: 안명근체포 → 백오인사건 단일 확대 구조를, 안명근체포 → 안악사건 → 백오인사건 2단계 확대 구조로 재구성. 안악사건 자체가 별도의 역사적 단계이므로.

### 6-2. 강하게 권장되어 반영한 것 4가지

`hasObject` comment를 "사건의 주체"에서 "사건의 핵심 참여자 또는 변화의 중심 대상"으로 수정(체포·해임처럼 대상이 행위자가 아닌 경우를 포괄하기 위함), `hasPreObject`/`hasPostObject` comment에 "관련 사건"을 포함(사건이 사건을 참조하는 패턴 반영), `hasBT owl:inverseOf hasNT` 추가와 comment 명확화, `hasFoundedYear`·`hasTimeValue`·`Group` 클래스 comment 보강.

### 6-3. 추가로 직접 검증해 반영한 날짜 5건

삼일운동 1919-01-01(placeholder) → 1919-03-01(확정, `hasEestimation` 0), 봉오동전투 → 1920-06-07(±1일), 청산리전투 → 1920-10-21(±5일), 조선물산장려회(조만식 설립 Event) → 1920-08-23(확정). 그 외 연도만 알려진 설립 Event(신흥무관학교 4건, 숭실학교, 보성학교, 대한독립군, 북로군정서 2건)에는 `hasEestimation "1"` + `RangeType "Year"`를 일괄 추가해, "연도만 아는데 1월 1일을 sentinel로 넣은 것"임을 추정모델로 명시했다.

> **미리 남겨두는 메모(§10에서 다시 다룸)**: 6-1의 오산학교 개교일 사례는 v6 안에서도 이미 작은 균열이 있었다 — 실제 Event의 `hasEventType`은 `:설립`(URI도 `이승훈설립_01`)인데, comment는 계속 "개교일"이라 부른다. "설립"이라는 유형과 "개교"라는 서술이 v6 시점부터 이미 뒤섞여 있었던 것이다. 이 틈이 v9에서 본격적으로 문제가 된다.

### 6-4. v6에서 의도적으로 보류한 것

최린의 "임명→전향"을 "중추원참의임명(사실)"과 "전향(해석)"으로 분리하는 안 — 출처가 정확한 전향 시점을 직접 지지하지 않아 근거 없이 나누는 것을 피함(이후 v9 계열 보고서의 "근거 없이 Claim을 나누지 않는다" 원칙과 같은 결의 판단이 여기서도 이미 한 번 나타난 셈이다). 신흥강습소→신흥무관학교 조직승계 모델링, `hasEvidenceStatus` 등 검증상태 속성 신설, `hasWebResource`/`hasBibo`의 타입 변경 — 모두 유보.

## 7. v6 → v7 — "사건 날짜 자동상속 금지" 원칙의 최초 대규모 적용

v7은 외부 개선안(문서20) 중 v6이 아직 반영하지 않은 부분만 골라 적용한 버전이다. 가장 중요한 대목은 사건의 날짜를 그 사건에 참여한 인물에게 무비판적으로 상속하지 않는다는 원칙이, **이 프로젝트 전체에서 시간상 최초로 데이터에 대규모로 명시 적용된다**는 점이다(같은 원칙이 훗날 별도 병렬 트랙(ver3~ver5, §10)에서 Rule P-03/G-02로 다시 독립적으로 재발견되어 명문화되지만, 그것은 이 시점보다 나중 일이다 — 시간순으로는 v7이 먼저다).

### 7-1. 소속 Event 시간정보 12건

신민회 소속 이벤트 7건(이승훈·안창호·양기탁·최광옥·이종호·이회영·이시영)에 1907년(Year 추정) 적용 — 한국민족문화대백과사전/Encyves Wiki의 신민회 창건위원·중심인물 공식 명단과 교차확인. **김좌진소속신민회_01은 반대로 이 공식 명단에 없음을 발견**해 날짜를 부여하지 않고 "재검증 강력권장" 코멘트를 남겼다 — 이 판단이 이후 v8에서 `hasValidationStatus` 신설로 이어지고, 다시 v9 계열에서 정정된다(§10 참조).

대한민국임시정부 소속 이벤트 5건(안창호·이시영·이동녕·이승만·이동휘)에는 1919년(Year 추정)을 적용했다. **차이석만 예외**로 두었는데, 기존에 확인된 "1933년 임시정부 재건 참여"를 반영해 1919가 아니라 1933을 부여했다 — 사건 시점 자동상속 금지 원칙이 실제로 적용된 첫 사례다.

### 7-2. 3·1운동 참여 Event — 확정 6건과 예외 3건

손병희·이승훈·한용운·오세창·최린·이종일 6건은 Encyves Wiki "민족대표 33인" 항목의 "태화관 불참 4인(길선주·유여대·김병조·정춘수)" 명단에 포함되지 않음을 확인해 1919-03-01(확정, `hasEestimation` 0)을 부여했다.

반대로 **정춘수는 그 불참 4인 명단에 정확히 포함**되어 있음을 발견 — 33인 서명자인 것은 맞지만 3/1 당일 참여 형태가 다르므로 날짜를 부여하지 않고 그 이유를 코멘트로 남겼다. **박희도**는 초기에 별도 조직을 꾸리려다 이후 합류한 복잡한 경위가 확인되어 시점 확정을 보류했다. **조만식**은 애초에 33인이 아니며 평양 지역 시위 가담으로 참여 성격 자체가 다름을 명시했다.

### 7-3. 설립 vs 공동설립 구분

신흥무관학교 4인(이회영·이시영·이동녕·이상룡), 북로군정서 2인(김좌진·서일)의 `hasEventType`을 `:설립`에서 신설한 `:공동설립`(`hasBT :설립`)으로 변경했다. 여러 인물이 각자 독립적으로 "설립"이라는 사건을 개별로 일으킨 것이 아니라, 하나의 공동 설립 행위에 함께 참여한 것임을 구조적으로 표현하기 위함이다.

### 7-4. 경영 관계 의미 재확인

이종일의 "경영"은 보성학교 전체가 아니라 부속 인쇄소 보성사 경영이었음을 코멘트로 구분했다(단, 이때는 아직 `hasPostObject` 자체는 `:보성학교`로 남아 있어 "코멘트가 데이터를 정정하는" 구조적 결함이 있었고, 이는 v8에서야 실제로 고쳐진다). 이종호는 보성학교 자체 경영권 인수로 그대로 유지했다.

### 7-5. v7에서도 손대지 못하고 넘긴 것

천도교 소속 이벤트(손병희·오세창·최린)의 가입 시점, 신간회 소속 이벤트(조만식·박희도)의 가입 시점, "영향"(이상룡→양기탁, 이승훈→안창호) 관계의 근거 문구 자체 재검증, "사사"(함석헌←유영모) 직접 사승 관계 확인, 재직/졸업 사실관계 확인, `hasBibo` 품질 통일과 comment 내 버전이력·데이터설명 분리.

## 8. v7 → v8 — 우선순위 3건과 "사건의 존재 자체"에 대한 불확실성 모델링

v8은 초기에 4개 영역으로 잡혔던 최우선(P0) 처리 대상이, 사용자의 재대조를 거치며 3건으로 압축된 결과를 반영한 버전이다(신흥강습소 관련 문제 하나는 성격이 달라 별도로 분리됐다 — 아래 8-4 참조). 여기서 온톨로지 설계상 가장 중요한 진전이 나온다 — **날짜가 틀렸다는 것과 그 관계·사건이 애초에 존재했는지가 불확실하다는 것은 다른 문제**라는 구분이 처음으로 속성 레벨에서 분리된다.

### 8-1. 임시정부 소속 4건 개별 재검증

- **이동휘**: 직접 재검색. 위키백과·세계한민족문화대전은 "8월말 도착·취임", 우리역사넷은 "9월 18일 도착, 11월 3일 정식 취임" — 출처 간 불일치를 그대로 반영해 1919-09(±2개월)로 조정. v7의 1919-01-01(임정 창립일을 그대로 상속받은 값)은 명백한 오류였다고 명시했다.
- **이승만**: 1919-09-11 통합임시정부 대통령 선출로 확정(`hasEestimation` 0). 단 실제 상해 현지 부임(1920-12-08)과는 다른 사건임을 명시 — "선출"과 "부임"을 혼동하지 않도록 코멘트로 경계를 그었다.
- **이동녕/이시영**: 사용자가 제공한 한국민족문화대백과사전 인용(이동녕 4/13 임시의정원 의장 선임, 이시영 4월 조직 참여)을 채택하되, 이번 세션에서 원문 URL을 직접 재확인하지 못했음을 정직하게 코멘트에 남겼다(간접 인용 표시) — 근거의 출처(직접 확인 vs 간접 인용)까지 구분해 기록한 사례.

### 8-2. 이종일-보성사 구조 분리

`:보성사` Group을 신설해 `:isGroupPartOf :보성학교`로 연결하고, `이종일경영보성학교_01`의 `hasPostObject`를 `:보성학교`에서 `:보성사`로 정정했다. v7까지는 "코멘트가 데이터를 정정하는" 구조적 결함이 있었는데, v8에서 실제 트리플이 코멘트의 설명과 일치하도록 고쳤다.

### 8-3. 김좌진-신민회 — 삭제 대신 "검증보류" 상태 도입

`:hasValidationStatus` 데이터속성을 신설했다. 값 "검증보류"를 부여해 SPARQL 질의나 시각화에서 정상 fact와 구분해 격리할 수 있게 했다 — 완전히 삭제하지 않는 이유는 향후 반증 근거가 나오면 복원하기 쉽게 하기 위함이다. 이 판정의 근거는 "한국민족문화대백과사전/Encyves Wiki의 신민회 공식 명단에 김좌진이 없다"는 것 하나였다 — 인물 자신의 항목까지는 이때 확인하지 않았다. **이 빈틈이 v9에서 메워진다**(§10 참조).

### 8-4. 신흥강습소/신흥무관학교 모델 재설계

단순히 "1911→1912 날짜를 수정"하는 문제가 아니라 실체 자체를 분리했다. `:신흥강습소`(1911, 설립 당시 정식 명칭) Group을 신규로 만들고, 이회영·이시영·이동녕·이상룡의 "공동설립" 대상을 `:신흥무관학교`에서 `:신흥강습소`로 정정했다. 신흥강습소→신흥무관학교 "개칭" Event를 별도로 만들되, **이 개칭 자체가 실제로 있었는지**(공식 명칭이 계속 신흥강습소였다는 서술도 존재)까지 불확실함을 인정하는 코멘트를 남겼다. 이는 지금까지의 "날짜 오차 추정"과는 다른 새로운 유형의 사례 — **사건의 존재 자체에 대한 불확실성**을 표현한 것이다.

### 8-5. v8에서도 손대지 못하고 P1로 넘긴 것

홍범도-봉오동전투/청산리전투 Month 단위 보강, 북로군정서 김좌진/서일 역할 비대칭(총재 vs 사령관) 반영, 천도교 소속 3건(손병희·오세창·최린) 재검색, 안명근-안악사건 "참여" 관계와 기존 체포/확대 이벤트 간 의미 중복 정리.

## 10. 지금까지의 결론, 그리고 v9와의 관계

- v1~v3은 표현력을 넓히는 방향(이항관계 → 사건 중심), v4~v5는 그 표현을 누가 언제, 얼마나 넓게 채워넣었는지의 기반을 다지는 방향, v6~v8은 실제 채워진 내용 하나하나가 맞는지 검증하고 맞지 않을 가능성 자체를 데이터로 남기는 방향으로 움직였다.
- `hasEestimation`(날짜가 확실한가)만으로는 부족한 지점이 v8에서 분명해졌다 — "그 관계가 애초에 존재했는가"(`hasValidationStatus`, 김좌진-신민회)와 "그 사건이 실제로 일어났는가"(신흥강습소 개칭 이벤트의 존재 자체에 대한 불확실성)는 날짜 정밀도와는 다른 축의 질문이다.
- "복수 출처가 일치한다"는 것도 재검증 대상이다 — v6이 오산학교 개교일을 "독립운동인명사전·위키백과·나무위키 등 복수 출처 일치"로 확정했지만, 그 근거 조합 자체가 서로 다른 두 종류의 서술(학교 연혁의 "12월"과 인물 항목의 실제 서술)을 짜깁기한 것이었다는 사실이 나중에 드러났다(§10 아래 이어지는 v9 문서 참조). 출처의 개수보다 각 출처가 실제로 무엇을 직접 말하고 있는지가 더 중요하다는 교훈이 여기서 나온다.
- P1로 계속 넘어가고 있는 항목들(천도교 3건, 안명근-안악사건 관계중복, 홍범도 전투참여 날짜 등)은 아직 완료되지 않은 채로 정직하게 남아 있다.

**v9와의 관계**: v9는 v8의 다음 버전 번호가 아니다. v8 인스턴스 데이터(특히 위에서 다룬 날짜·관계 판정들)의 근거가 실제로 충분한지를 49개 항목 단위로 재검증하기 위해 병렬로 구축된 별도의 Provenance 데이터셋 계열이며, 이 트랙은 v8과 시기가 겹치는 동안 독립적으로 시작해 v8이 다루지 못한 "Claim 단위 증거 추적" 문제를 다룬다. 자세한 내용은 별도 문서("온톨로지 v9 계열 전체 정리")에서 다룬다.

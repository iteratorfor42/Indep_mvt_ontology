# v7 검증 보고서

## — v8 추가검증보고서(ver5) 원칙을 소급 적용한 v7 TTL 감사

> 본 보고서는 v9 계열에서 확립된 "v8 추가검증보고서(ver5, 설계 승인본)"의 원칙(Claim/Evidence/Source 분리, claim_status·date_status·review_flag 독립성, 사건 날짜 자동상속 금지 등)을, 그 원칙이 아직 존재하지 않았던 시점의 산출물인 **v1~v8 TTL 본체의 v7 스냅샷**에 소급 적용해 감사한다. v7 자체 코멘트가 이미 자인하고 있는 미해결 항목과, 그 코멘트에는 없지만 ver5 기준으로 보면 문제가 되는 항목을 함께 정리한다.

---

## 0. 이 보고서가 검증하는 대상

- **입력**: 업로드된 v7 TTL(v4→v5→v6→v7 변경사항 changelog + 클래스/속성 정의 + 8~9절 인스턴스 데이터 전체)
- **위치**: v1~v8 TTL 본체 트랙에서 v6과 v8 사이. v9 계열(Claim/Evidence/Source 방법론)이 시작되기 전 시점의 스냅샷이다.
- **목적**: v7이 "그 다음 버전인 v8에서 왜 더 고쳐야 했는가"를 ver5의 언어로 명확히 하는 것. v7 자체는 이미 "v7에서도 아직 손대지 못한 것"이라는 절을 두고 있어 스스로 미완성 지점을 인지하고 있었다 — 이 보고서는 그 인지 목록과, v7이 인지하지 못한 채 남겨둔 구조적 문제를 구분해서 본다.

## 1. v7이 이미 스스로 인지하고 있던 미해결 지점 (v7 코멘트 원문 기준)

v7 changelog 말미의 "v7에서도 아직 손대지 못한 것" 절은 다음을 명시하고 있다.

```text
- 천도교 소속 이벤트(손병희·오세창·최린)의 가입 시점 — 여전히 미상
- 신간회 소속 이벤트(조만식·박희도)의 가입 시점 — 여전히 미상
- "영향"(이상룡→양기탁, 이승훈→안창호) 관계의 근거 문구 자체 재검증
  (가장 해석적인 관계유형이라 가장 보수적으로 다뤄야 함)
- "사사"(함석헌←유영모) 직접 사승 관계 확인
- 재직/졸업 사실관계 확인
- hasBibo 품질 통일, comment 내 버전이력과 데이터설명 분리
```

ver5의 언어로 재진술하면: 이 항목들은 전부 **`claim_status`가 사실상 `not_directly_verified`인 채로 방치**되어 있으며, `hasBibo`(v9의 `source_title`에 대응)만 있고 `Evidence`(문장 단위 근거) 없이 사건이 존재한다. ver5 Rule P-01("출처 URL의 존재가 곧 값의 검증을 뜻하지 않는다")을 그대로 어기는 상태로, v7도 이를 알고 있었기에 시간정보를 부여하지 않는 선에서 멈췄다 — 이 판단 자체는 ver5 원칙과 일치한다(근거 없이 확정하지 않은 것).

## 2. v7이 인지하지 못한 채 남겨둔 문제 4건

### 2-1. 오산학교 — hasEventType(설립)과 코멘트(개교)의 내부 불일치

`:19071224이승훈설립_01`은 `hasEventType :설립`이고 URI도 `이승훈설립_01`인데, v6 changelog 코멘트와 Event 자체의 `rdfs:comment`는 계속 "**개교**일을 수정했다"고 서술한다.

```text
hasEventType = :설립   (유형)
comment      = "개교일을 ... 수정"   (서술)
```

ver5 §4-2 기준으로 보면 이는 **하나의 Claim 안에 두 개의 서로 다른 사건(설립/개교)이 섞여 있는 상태**다. v9 ver2가 나중에 「이승훈」 항목 원문을 직접 열어 "1907년 11월 24일"이라는, v6이 "다출처 일치"로 확정했던 날짜와 다른 값을 발견하는데, 그 원인 중 하나가 바로 이 설립/개교 혼용이다 — 학교 연혁 쪽 출처는 "설립"(12월)을 말하고 인물 항목은 "개교"(11월 24일)를 말하고 있었을 가능성이 크며, v6~v7은 이 둘을 하나의 Event로 뭉뚱그려 "복수 출처 일치"라고 판정했다.

**판정**: 이 문제는 v7 시점까지 발견되지 않았고, v8에서도 고쳐지지 않았다. 실제로는 v9 ver2~ver4에서야 별도 Claim(CLM-OSAN-01 설립/CLM-OSAN-02 개교)으로 분리된다.

### 2-2. 이종일-보성학교 — hasPostObject와 코멘트의 불일치

`:이종일경영보성학교_01`의 `hasPostObject`는 `:보성학교`인데, `rdfs:comment`는 "이종일의 '경영'은 보성학교 전체 운영이 아니라 부속 인쇄소 '보성사'의 사장으로서…"라고 이미 서술하고 있다. 즉 **v7 스스로 코멘트에서 데이터가 틀렸다고 말하면서도 트리플 자체는 고치지 않았다.**

ver5의 언어로: `claimText`(comment)와 `hasObject`(구조화된 필드)가 서로 다른 사실을 가리키는, ver5 §4-6에서 경계했던 "코멘트가 데이터를 정정하는" 전형적인 사례다.

**판정**: v7에서 발견됐지만(코멘트로 남김) 미수정. v8에서 `:보성사` Group을 신설해 실제로 고쳐진다(P0-2).

### 2-3. 신흥무관학교 — 4인 공동설립의 대상이 이미 시대착오적

이회영·이시영·이동녕·이상룡의 `hasEventType`은 v7에서 `:공동설립`으로 정정됐지만(문서20 5·6번 반영), `hasPostObject`는 여전히 `:신흥무관학교`다. 그런데 이 조직의 1911년 설립 당시 정식 명칭이 신흥강습소였고 신흥무관학교라는 명칭이 언제 공식화됐는지 자체가 불확실하다는 사실은 v7 changelog 어디에도 언급되지 않는다.

**판정**: v7에서는 문제로 식별조차 되지 않았다. v8에서 `:신흥강습소` Group을 신설하고 개칭 Event를 별도로 만들면서 처음 다뤄진다(P0-4/P0.5) — "날짜 오차"가 아니라 "실체 자체가 잘못 연결되어 있었다"는 점에서, ver5 §4의 Claim 분해 원칙이 나중에 적용될 대표 사례가 여기서 이미 잠복해 있었던 셈이다.

### 2-4. 김좌진-신민회 — "재검증 강력권장"이 상태값으로 격리되지 않음

v7은 신민회 공식 명단에 김좌진이 없음을 직접 확인하고 "재검증 강력권장" 코멘트를 남겼지만, 이 Event는 여전히 다른 정상 fact들과 **동일한 그래프에 구분 없이** 존재한다. `hasEventType :소속`이 그대로 있고, SPARQL로 이 Event만 걸러낼 방법이 없다.

**판정**: v7까지는 "코멘트로 경고"하는 수준. v8에서 `hasValidationStatus="검증보류"`가 신설되며 처음으로 기계가 읽을 수 있는 격리 장치가 생긴다(P0-3). v9 ver4는 반대로 「김좌진」 개인 항목에서 직접 서술을 찾아 confirmed로 정정한다 — v7이 놓쳤던 것은 "조직 명단만 확인하고 인물 본인의 항목은 확인하지 않았다"는 점이다.

|---|---|---|---|
| 오산학교 설립/개교 혼용 | hasEventType=설립, comment=개교 | Claim 미분해(1개 Event에 2개 사실) | v9 ver2~ver4 (CLM-OSAN-01/02) |
| 이종일-보성학교/보성사 | hasPostObject=보성학교, comment는 보성사라고 서술 | 코멘트가 데이터를 정정하는 구조적 결함 | v8 P0-2 |
| 신흥무관학교/신흥강습소 미분리 | 4인 공동설립 대상이 신흥무관학교로 고정 | 실체(Group) 오귀속, 문제 자체가 미식별 | v8 P0-4/P0.5 |
| 김좌진-신민회 검증보류 | 코멘트만 존재, 상태값 없음 | Negative evidence가 기계가독 형태로 격리 안 됨 | v8 P0-3(hasValidationStatus), v9 ver4(정반대 정정) |
| 천도교 3건, 신간회 2건 가입시점 | 시간정보 미상, "재검증 권장"만 코멘트 | claim_status 미확정 상태 방치(단, 근거 없이 확정하지 않은 것은 ver5 원칙과 일치) | v8 P1로 이월, 이 보고서 시점까지도 미해결 |
| 이승만/이동휘 등 임시정부 소속 5건 | 전부 1919-01-01(Year 추정) 일괄 부여 | 사건(임정 창립) 날짜를 개인에게 자동 상속 — ver5 Rule G-02 정면 위반 소지 | v8에서 이승만 1919-09-11 확정, 이동휘 1919-09±2개월로 개별 재검증(P0-1). 단 이동녕·이시영은 v8까지도 간접 인용 상태로 남음 |
| "영향"/"사사" 관계 근거 문구 | 재검증 필요 인지만 하고 미착수 | Evidence 텍스트 자체가 없음 | v8까지도 미해결(P1) |

## 4. v7 시점에서 ver5 원칙을 가장 잘 지킨 사례

비판만 있는 것은 아니다. v7의 다음 두 판단은 ver5 원칙과 정확히 일치한다.

- **정춘수**: "태화관 불참 4인" 명단에 있다는 사실을 발견하고도, 다른 서명자들처럼 1919-03-01을 일괄 부여하지 않고 시간 미상으로 유지한 것 — ver5 Rule G-02(사건 날짜 자동상속 금지)를 앞서 실천한 사례.
- **차이석**: 임시정부 소속을 1919년 창립기가 아니라 실제 확인된 "1933년 재건 참여"로 부여한 것 — 이 역시 같은 원칙의 실천이다.

이 두 사례는 v7 changelog 스스로도 "사건 시점 자동상속 금지 원칙의 실제 적용"이라고 명시하고 있어, ver5가 나중에 별도로 이 원칙을 재발견하기 전에 이미 실무적으로 지켜지고 있었음을 보여준다.

## 5. 결론

| 영역 | 판정 |
|---|---|
| v7이 자인한 미해결 항목(천도교·신간회·영향·사사·재직졸업) | 정직하게 방치됨 — ver5 기준으로도 "근거 없이 확정 안 함"은 올바른 판단 |
| 오산학교 설립/개교 혼용 | v7 시점에 이미 존재, 식별 안 됨 — 후속 v9에서 발견 |
| 이종일 보성사 문제 | v7이 코멘트로 인지했으나 데이터는 미수정 — v8에서 해소 |
| 신흥무관학교/신흥강습소 실체 오귀속 | v7 시점에 문제로 식별조차 안 됨 — v8에서 처음 다뤄짐 |
| 김좌진 검증보류 | 코멘트 수준 경고만 존재, 기계가독 격리 장치 없음 — v8에서 hasValidationStatus 신설 |
| 임시정부 소속 날짜 일괄부여(1919-01-01 Year) | Rule G-02 위반 소지 — v8에서 부분 해소(이승만/이동휘), 이동녕/이시영은 v8까지도 간접인용 상태 |
| 사건 날짜 자동상속 금지 원칙의 선제적 실천(정춘수·차이석) | 통과 — ver5 원칙을 앞서 실천한 사례로 남길 가치 있음 |

**총평**: v7은 "이 문서가 무엇을 모르는지 스스로 알고 있다"는 점에서 정직한 중간 산출물이다. 다만 ver5 기준으로 보면 v7이 놓친 것은 v7이 자인한 목록보다 오히려 **자인하지 않은 목록**(오산학교 설립/개교 혼용, 신흥강습소 실체 오귀속)이 더 크다 — 이 두 건은 "무엇을 모르는지도 몰랐던" 경우이며, 각각 별도 트랙(v9, v8)에서 우연히 다른 작업을 하던 중 발견됐다는 점이 시사하는 바가 있다: **자체 changelog의 자기인지만으로는 구조적 문제를 다 잡아낼 수 없고, 외부 검증(v9 계열의 원문 재대조, v8의 실제 파일 재검토)이 필요했다.**

|---|---|
